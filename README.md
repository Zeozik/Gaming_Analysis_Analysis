# Анализ влияния игр на продуктивность

**Полный EDA датасета "Gaming Hours vs Academic & Work Performance"**

## Основные выводы
- Игровое время **не коррелирует** с успеваемостью
- **Ночные игроки** показывают лучшие результаты
- **Студентки** - самая успешная группа
- **Жанр игр** важнее, чем время игры

## Файлы
- `gaming_productivity_analysis.ipynb` - полный анализ в Jupyter
- `gaming_productivity_dataset.csv` - данные
- `requirements.txt` - список библиотек Python

## Технологии
- Python, Pandas, Matplotlib, Seaborn
- Статистический анализ

*Исходный датасет: [Kaggle](https://www.kaggle.com/datasets/prince7489/gaming-hours-vs-academic-and-work-performance)*
